How the faces are built

  • Same cloud body, cheeks and colors as Ulap (design-spec §8.2). No new character.
  • Faces are made only from Ulap's existing parts: eyes, brows and mouth, plus a small prop in the empty top corner for some moods (sweat drop, steam puff, scribble, "z", heart, star, leaf).
  • Softened, following §8.5: no tears, no shouting mouths, nothing that looks sick. Angry gets a small steam puff, not red anger marks. Sad gets a soft frown, not tears.
  • Hopeless uses Ulap's existing quiet face exactly as it is: small eyes, a short flat line and no prop. It's the same face the Hopeless response screen shows.
  • At tile size the face lines are drawn a little thicker than on the big Ulap, so they stay readable at tile size (46dp wide, with the empty margin around the cloud cropped).
  • Tiles get about 20dp taller. The screen scrolls about 200dp further.
  • TalkBack still reads "Worried. Red Zone. Default stress 8." The face is decoration, so TalkBack skips it.
