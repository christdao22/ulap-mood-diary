# Contributing to Ulap

Thank you for helping make Ulap kinder and better. 💙

The contributing guide is [README §12](README.md#12-contributing-guidelines): ground rules, branches, commits, code style, the pull request checklist and reviews. This file only points there, so the rules stay in one place ([README §17](README.md#17-documentation)).

Before you start:
- Set up the project with [README §6](README.md#6-getting-started-development).
- Find the task in [PHASES.md](PHASES.md). Open an issue first for anything bigger than a small fix.
- Report security issues privately ([README §14](README.md#14-privacy-safety-and-data-handling)), never in a public issue.
